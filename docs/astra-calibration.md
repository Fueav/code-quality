两个模型均检出两个阻断缺陷，并放过两个反例。每个正例执行一次原生发现和一次受限裁决；反例只执行原生发现。被审查仓库的 HEAD、文件和 Git 状态保持不变。

本轮 Astra 的总输入 token 和总耗时更少，但单次小样本、缓存命中和共享机器负载不足以支持更换全局默认。v0.5.11 保留 Sol/max 默认；用户仍可显式选择 Astra 和 effort。只读裁决、冻结证据、`FULL → INCREMENTAL` 轮次和生产下限不变。
